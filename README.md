# DevOps AI Agent Project 🚀

Welcome to the **DevOps AI Agent Project**! This repository contains a simple implementation of an AI agent that can research and summarize topics using Crew AI. The project is designed for beginners with zero coding experience and zero cost. 🎉

---

## 📝 **Project Overview**
This project leverages **Crew AI** to create two agents:
1. **Research Agent**: Gathers information on a given topic.
2. **Summarizing Agent**: Condenses the gathered information into a concise summary.

The default setup provided by Crew AI allows you to easily modify the topic in the `main.py` file.

---

## 💻 **Installation and Setup**
Follow these steps to set up the project:

### 1️⃣ Check Python Version
Ensure Python is installed on your machine. Run:
```
python --version
```


### 2️⃣ Create a Virtual Environment
To avoid version conflicts, create a virtual environment:
```
python3 -m venv crew # You can name this environment anything you like
```


### 3️⃣ Install Crew AI
Activate your virtual environment and install Crew AI:
```
pip3 install crewai
```


### 4️⃣ Create Your Project
Generate the default agents using Crew AI:
```
crewai create devops_ai_project
```

During this step, you'll be prompted to select the Large Language Model (LLM) available on your machine.
